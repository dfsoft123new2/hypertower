### Codex 的详细贡献

- **XI–XX 纪元的全部代码**：完成从九头纪元到绝对纪元的程序实现，涵盖各纪元机制、交互界面、谜题沙盒、设计验证、研究与进度推进，以及归一轮回等系统。
- **XXI–XXIV 与 ∞ 的后端代码**：实现群星纪四个 DLC 纪元、无限循环及其共通系统的状态、规则、计算和存档逻辑，提供前端所需接口，并参与联调、冲突处理与规则补齐。
- **存档与历史记录维护**：处理版本迁移、存档恢复与兼容问题，制作备用通关及联调存档，修复成就和历史记录相关问题，并排查 X→XI、XX→XXI 等跨阶段入口衔接。
- **Bug 修复与操作体验改进**：根据测试反馈排查并修复多项按钮响应、状态刷新、操作结果反馈、规则冲突和边界条件问题，持续完善开发调试与验证流程。
- **性能优化**：持续排查后期运行变慢和操作延迟，优化状态更新、界面刷新、重复计算及缓存等环节，结合回归检查改进运行与交互性能。
- **规则审计、可达性与回归验证**：核对实现与设计文档的差异，检查收集目标和实际可达数量，修正相关目标，验证存档、纪元推进、循环与自动化等流程，并配合前后端联调。
- **文档整合与完整介绍编写**：整理、合并多份群星纪设计文档；编写 I–XXIV 与 ∞ 的详细介绍，分别说明 P1、P2、P3，各纪元的具体玩法、资源、重置、入口及阶段之间的联系，并补充整体介绍、术语和路线速查。
- **介绍网站与阅读界面制作**：把长篇介绍制作成网页，加入章节目录、章节搜索、阅读进度、手机适配、打印与 PDF 保存，以及配图放大、原尺寸查看、前后翻图、键盘操作、配图筛选和纯文字阅读切换。
- **截图与配图整理**：制作亮色电脑版全纪元截图和 X→XI、XX→XXI 入口截图，补拍具体操作并裁切局部图、编写图注；当前介绍包含 **194 幅配图（33 张完整界面、161 张局部图）**。另外制作 P1 高 ε、P2 数十万次归一、P3 数十万与百万圈的隔离存档演示，明确标注预置进度。
- **发布与上线检查**：整理网页、原图、预览图、公开配图清单与完整界面图集，修正发布路径；上传前扫描敏感字符串，按拉取、rebase、提交和推送流程更新 GitHub，并检查 Pages 部署、线上页面和图片资源。
